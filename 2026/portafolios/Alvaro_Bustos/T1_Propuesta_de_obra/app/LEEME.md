# Keyboard Instruments: cómo tocar

Programa listo para tocar, sin instalar Python:

| Sistema | Archivo | Cómo abrirlo |
|---|---|---|
| Windows 10/11 | `KeyboardInstruments-Windows.zip` | Descomprimir y abrir `KeyboardInstruments/KeyboardInstruments.exe`. Si aparece «Windows protegió su PC»: **Más información → Ejecutar de todas formas**. |
| macOS (Apple Silicon) | `KeyboardInstruments-macOS.zip` | Descomprimir y abrir `KeyboardInstruments.app` con **clic derecho → Abrir** la primera vez. (Mac Intel: usar el código, ver abajo.) |
| Linux | `KeyboardInstruments-Linux.tar.gz` | `sudo apt install libportaudio2`, luego `tar xzf KeyboardInstruments-Linux.tar.gz` y `./KeyboardInstruments/KeyboardInstruments`. |

## Desde el código (Python 3.10+)

Descomprimir `keyboard-instruments.zip` y usar `run_windows.bat` (Windows), `run_macos.command` (macOS) o `run_linux.sh` (Linux).
