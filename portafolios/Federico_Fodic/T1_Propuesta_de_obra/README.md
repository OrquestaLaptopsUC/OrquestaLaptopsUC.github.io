# PULSO 128 - archivos de entrega

Estructura recomendada para subir al portafolio:

```text

├── PULSO128_v2.html
├── Propuesta_PULSO128.pdf
├── pulso128_demo_45s.wav
├── README.md
└── Documentacion/
    ├── Documentacion_PULSO128.pdf
    ├── documentacion_pulso128.md

```

## Qué abrir primero

- Propuesta: `Propuesta_PULSO128.pdf`
- Instrumento web: `PULSO128_v2.html`
- Render: `pulso128_demo_45s.wav`
- Instrucciones técnicas: `Documentacion/documentacion_pulso128.md`

No es necesario subir un video para cumplir el enunciado de T1: el material sonoro requerido es un render de audio de 30 a 90 segundos. Si se agrega un video, puede ser material complementario.

## Presentación oral

Usa `Guion_presentacion_5min.md`. Está dividido siguiendo la pauta sugerida por el enunciado: idea/referentes, estructura/coordinación, material sonoro y riesgos/cierre.
